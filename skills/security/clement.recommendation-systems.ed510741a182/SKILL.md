# Recommendation Systems

Design, implement, review, debug, or operate the named technology using reproducible engineering practices.

## Activation
- Use when the user explicitly asks for recommendation systems.
- Use when a task would materially benefit from the methods, standards, or operating style associated with recommendation systems.
- Use for implementation, debugging, architecture, migration, testing, setup, review, or operation involving the named technology.

## Operating instructions
1. Confirm the target environment, versions, constraints, inputs, interfaces, performance goals, and definition of done.
2. Inspect existing assets and documentation before changing or generating implementation details.
3. Choose the simplest architecture that satisfies functional, security, reliability, maintainability, and cost requirements.
4. Implement in small verifiable steps with explicit configuration, error handling, validation, and observability.
5. Test normal paths, edge cases, failure paths, compatibility, performance, and security-relevant behavior.
6. Document setup, assumptions, commands, interfaces, data flows, rollback, and operational ownership.
7. Review for secrets, unsafe defaults, destructive operations, licensing issues, and dependency risks.
8. Provide reproducible artifacts plus a verification checklist and known limitations.

- **Executive Summary**: Concise answer or decision-ready overview.

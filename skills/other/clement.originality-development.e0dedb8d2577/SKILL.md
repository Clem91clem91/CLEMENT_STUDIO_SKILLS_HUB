# Originality Development

Generate, develop, select, and refine original ideas that serve a defined objective and constraints.

## Activation
- Use when the user explicitly asks for originality development.
- Use when a task would materially benefit from the methods, standards, or operating style associated with originality development.
- Use when the task requires original options, concepts, narratives, visual directions, or innovation.

## Operating instructions
1. Translate the brief into an objective, audience, constraints, required emotion, references, and success criteria.
2. Gather diverse inputs while separating inspiration from imitation and respecting rights and originality.
3. Generate a broad option space using multiple creative lenses, combinations, and controlled constraints.
4. Cluster and compare concepts for relevance, novelty, feasibility, distinctiveness, and strategic fit.
5. Develop the strongest concepts into concrete narratives, prototypes, examples, or visual directions.
6. Critique predictable, derivative, incoherent, inaccessible, or impractical elements.
7. Iterate using feedback and tests while preserving the core creative intent.
8. Deliver selected concepts, rationale, execution guidance, alternatives, and validation plan.

## Skill-specific focus
- Primary capability: Originality Development.
- Primary domain: design media creative.
- Apply originality development as an explicit repeatable protocol.
- Produce an artifact that another agent or human can review and reuse.
- State assumptions, uncertainties, and completion criteria.
